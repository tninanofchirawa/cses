# CSES Problem Set Solutions

A personal repository documenting solutions to the **[CSES Problem Set](https://cses.fi/problemset/)** in C++.

---

## About This Project

This is a **slow, deliberate marathon** rather than a sprint. 

The CSES problem set spans 400 problems covering standard competitive programming algorithms, data structures, and mathematical techniques. The goal here is not to rush through editorials or paste templates, but to genuinely understand the core logic, write clean implementations from scratch, and build lasting problem-solving intuition over time.

- **Language:** C++ (C++17 / C++20)
- **Target:** 400 / 400 problems
- **Pacing:** Consistent, deep work over quick completions
